# Improving Medical Visual Question Answering through Feedback-Augmented Answer Refinement

This repository contains the code and data for the paper:

**"Improving Medical Visual Question Answering through Feedback-Augmented Answer Refinement"**  
_Submitted to ACL 2025 Student Workshop_

---

## 🔍 Abstract

Recent vision-language models struggle with the demands of medical VQA, which require clinical reasoning and structured medical knowledge. We propose a feedback-based self-reflection framework that connects answer generation, feedback construction, and refinement in a closed loop. By leveraging structured natural language feedback, the model iteratively revises its answers without external supervision. Evaluated on 3,000 medical questions across four VLMs using metrics such as RadGraph F1, GPT-based scoring, and Medical-NER similarity, our approach yields consistent improvements—especially on clinically nuanced questions—demonstrating its potential to enhance accuracy and interpretability in medical VQA.
